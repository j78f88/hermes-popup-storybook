# Page checklist

Use this checklist after drafting each page and again after every visual change.

- [ ] Words are counted and fit the target range without scrolling.
- [ ] Facts match the ledger values, dates, wording, and stated limits.
- [ ] Sources resolve to exact references and support every displayed claim.
- [ ] Default, half-pulled, fully pulled, and lifted states work correctly.
- [ ] The start, half-pulled, fully pulled and lifted states show the planned change from start to result.
- [ ] Measured edges, overlaps, landing positions, and reading order are clean.
- [ ] Scene descriptions and controls remain clear for keyboard and screen readers.
- [ ] Phone, desktop, and print views preserve the intended story meaning.
